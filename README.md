# Vehicle Health System

A simple Java project I made while learning conditionals and user input.

The program takes some basic vehicle information and checks:

- Engine temperature
- Oil level
- Battery voltage
- Service interval

At the end, it shows whether the vehicle is healthy or needs attention.

## What I used

- Java
- Scanner
- if / else if / else
- boolean
- String.format()

## Version

v0.1

I will keep improving this project as I learn new Java topics.
